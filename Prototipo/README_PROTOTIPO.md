# NullBorn — Prototipo (archivado)

Copia del proyecto Unity **antes del reset stylized** (commit `5466f45`).

## Cómo abrir

1. Unity Hub → **Add** → selecciona esta carpeta `Prototipo/` (debe contener `Assets/`, `Packages/`, `ProjectSettings/`).
2. Unity **6000.5.9f1** recomendado.
3. Escenas principales:
   - `Assets/Scenes/World_Main.unity`
   - `Assets/Scenes/Combat_Arena.unity`
   - `Assets/Scenes/Demo_10min.unity`

## Nota

El desarrollo **nuevo** del juego (Nature + Village + personaje stylized) se hará en la raíz del repo cuando importes los assets de [`../ASSET_STACK.md`](../ASSET_STACK.md). Este prototipo queda como referencia y regresión.
